## Delivered API contract

All four routes require a valid JWT and `CUSTOMER` or `ADMIN`. They only use the JWT `sub`; path/query/body data cannot choose an owner. A valid JWT subject whose account row is gone receives `404 RESOURCE_NOT_FOUND`. There is no global account-state check.

| Method and path | Request | Success response |
|---|---|---|
| `GET /api/v1/me` | None | `200`: `account_id`, `email`, and `profile` (`null` until a profile exists; otherwise `{ "display_name": ... }`). Read-only. |
| `PATCH /api/v1/me` | `{ "display_name": "Nguyễn An" }` only | `200` with the GET shape. Creates or updates only `user_profile.display_name`. |
| `GET /api/v1/me/style-profile` | None | `200`: `{ "style_profile": null }` if no parent; otherwise all five scalar fields and three arrays. Read-only and consistently ordered. |
| `PUT /api/v1/me/style-profile` | Required: `fit_preference`, `height_cm`, `usual_top_size`, `usual_bottom_size`, `shoe_size`, `style_codes`, `color_codes`, `brand_ids` | `200` with the GET style shape. Full replacement; nullable scalars clear values, `[]` clears a collection. All-null/all-empty input creates an empty parent. |

Missing/null/blank `display_name`, missing/null collections, missing PUT properties, malformed or wrong-typed values, unknown properties, and duplicate canonical values return `400 INVALID_REQUEST`. Responses do not contain password hashes, account state, roles, or authentication material. Errors use existing Problem Details and correlation IDs.

### Approved validation and storage rules

| Input | Validation and normalization | Existing V1 storage |
|---|---|---|
| Display name | Trim Unicode White_Space; 1–100 Unicode code points; reject control characters; preserve remaining Unicode text. | `user_profile.display_name` |
| Fit/style/color codes | Nullable fit scalar; collection items non-null. Trim and match `^[A-Za-z0-9][A-Za-z0-9_-]{0,63}$`; uppercase with `Locale.ROOT`; reject duplicates after canonicalization. No finite vocabulary. | `style_profile.fit_preference`, `profile_style.style_code`, `profile_color.color_code` |
| Height | Nullable JSON number parsed as exact `BigDecimal`; 50–250 cm inclusive; at most one fractional digit; reject wrong type/range/precision without rounding. | `style_profile.height_cm` |
| Size labels | Nullable free-form labels; trim Unicode whitespace; 1–32 code points; reject blank/control characters; no size-system enum. | `usual_top_size`, `usual_bottom_size`, `shoe_size` |
| All three collections | Required, non-null arrays; at most 50 values each; `[]` clears; duplicates rejected. GET sorts each collection deterministically. | `profile_style`, `profile_color`, `profile_brand` |
| Brand IDs | Hyphenated UUID syntax; hex case-insensitive; duplicate UUIDs rejected; stored as logical references only. | `profile_brand.brand_id` |

Identity does not call Commerce or verify whether a syntactically valid brand UUID exists or is active. That is the approved US-02.05 boundary, not a defect or a claim of external validation.

### Transaction and ownership behavior

- Repository SQL is parameterized Spring JDBC. Reads use only `account`, `user_profile`, `style_profile` and its three preference tables.
- Writes lock the JWT-subject `account` row first. PATCH upserts the `user_profile` row. PUT upserts the style parent and replaces all three child collections in one transaction. Failures roll back the parent/scalars and every collection change.
- Concurrent first PATCHes and PUTs serialize on the account row; the last serialized request wins as one complete aggregate. PostgreSQL `pg_stat_activity` confirmed the concurrent request actually waited on the row lock; the test uses latches and observed database lock state, not a free-running sleep to establish ordering.
- Register behavior is unchanged and its PostgreSQL integration test now asserts that registration creates no `user_profile` or `style_profile` placeholder.

No migration, table, column, constraint, FK, seed, persistence framework, business schema or Commerce integration was added. V1–V3 were not edited.
