## May moi

Can Docker Desktop dang chay va JDK 21 trong PATH. Tu root clone:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Initialize-LocalPayment.ps1
docker compose up -d --build
```

Initializer chi tao moi `.env` va `.secrets/stylemind-identity-private.pem`;
tu choi ghi de file cu. Dung Mailpit local, Admin bootstrap mac dinh tat,
tai khoan ngan hang gia cho mo phong SePay. De test collection, cau hinh
Admin local truoc khi Identity khoi dong lan dau theo
[team setup](US-04.02_TEAM_SETUP.md). Khong commit/env export credential that.

## May da co stack va database

Giu password database, signing key va service token dang dung. Kiem tra `.env`:

```dotenv
STYLEMIND_COMMERCE_PAYMENT_TOKEN=<token-tao-attempt-hien-tai>
STYLEMIND_COMMERCE_SERVICE_TOKEN=<token-payment-events-hien-tai>
STYLEMIND_PAYMENT_EVENTS_ENABLED=true
```

Hai dau Commerce/Payment phai dung cung gia tri cho tung token tuong ung.
Khong dung literal `<...>`. Compose da truyen cac bien nay vao dung service.
Neu dependencies da chay, cap nhat Commerce truoc de ap dung V8, roi Payment:

```powershell
docker compose up -d --build --no-deps commerce-service
docker compose logs --tail 100 commerce-service
# Xac nhan Commerce khoi dong thanh cong, Flyway V8 thanh cong:
docker compose up -d --build --no-deps payment-service
docker compose logs --tail 100 payment-service
```

V8 chi mo CHECK payment_method cua inbox de chap nhan COD/SEPAY_VIETQR;
V7 va du lieu cu khong bi sua. Khong co migration Payment moi. Neu database
da co V8 khac, giai quyet lich su voi team; khong sua migration da chay,
repair mu hoac xoa volume. Bat dispatcher cung gui COD/SePay da SETTLED va
co ledger/outbox chua publish truoc do. Khong can Notification de thu COD
hoac gui PaymentConfirmed. Notification/Identity van co dependency rieng
cho cac luong khac cua stack.

Compose co project name `stylemind`; tranh chay hai clone/worktree cung
project/port tren cung may. `restart` khong lay image/code/env moi.
