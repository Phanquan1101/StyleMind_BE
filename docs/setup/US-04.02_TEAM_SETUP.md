## 4. May da co database/.env

KHONG chay lai initializer, doi password DB hay tao lai signing key.
Giu credential dang dung, them cac bien con thieu tu `.env.example`.
Sinh hai gia tri ngau nhien doc lap bang PowerShell (chay hai lan):

```powershell
$buffer = New-Object byte[] 32
$generator = [Security.Cryptography.RandomNumberGenerator]::Create()
$generator.GetBytes($buffer)
[Convert]::ToBase64String($buffer)
$generator.Dispose()
```

Dat ket qua vao `.env` cua chinh may do:

```dotenv
STYLEMIND_COMMERCE_PAYMENT_TOKEN=<ket-qua-thu-nhat>
STYLEMIND_COMMERCE_SERVICE_TOKEN=<ket-qua-thu-hai>
STYLEMIND_PAYMENT_EVENTS_ENABLED=true
STYLEMIND_JWT_JWK_SET_URI=http://identity-service:8081/.well-known/jwks.json
STYLEMIND_JWT_JWS_ALGORITHM=RS256
STYLEMIND_SEPAY_WEBHOOK_AUTH_MODE=hmac
STYLEMIND_SEPAY_WEBHOOK_SECRET=<secret-khop-voi-cau-hinh-webhook>
```

Khong de nguyen dau `<...>`. Compose truyen moi service token tu cung mot
bien vao ca Commerce va Payment: hai dau cua cung mot ket noi phai khop.
Hai token nay khac JWT nguoi dung, secret OTP va credential SePay.
Moi may local co the dung secret khac nhau; nhieu service cung moi truong
phai dung chung gia tri tuong ung. Tranh khai bao bien trung lap.

Bat dispatcher tren database cu se gui ca outbox SePay chua publish truoc do.
Kiem tra du lieu ton va Order truoc khi bat. Order huy/terminal se duoc ghi
exception de doi soat, khong duoc revive.

## 6. Kiem tra sau khi chay

- Gateway: `http://localhost:8080`. Commerce OpenAPI:
  `http://localhost:8080/commerce/v3/api-docs`; Payment:
  `http://localhost:8080/payment/v3/api-docs`.
- Mailpit: `http://localhost:8025` (email OTP local, khong gui SMTP that).
- Tao tai khoan, xac minh email va login bang collection Identity; dung checkout
  va payment recovery trong [handoff guide](../../postman/US-04.01_CREATE_SEPAY_PAYMENT_RUN_GUIDE.md)
  de tao Order SePay va lay reference/amount. Endpoint tao payment public cu
  con phu thuoc snapshot API Commerce chua co; dung checkout/recovery.
- Import [collection US-04.02](../../postman/StyleMind-US-04.02-Confirm-Payment.postman_collection.json)
  va doc [run guide](../../postman/US-04.02_CONFIRM_PAYMENT_RUN_GUIDE.md).
  Dien local `webhookSecret`, `webhookAuthMode=hmac`, JWT va reference/amount
  cua Order test. Secret mac dinh trong collection rong; khong export gia tri that.
- Gui exact amount, gui lai cung provider event ID; doi polling (mac dinh 10 giay),
  doc Order de thay PAID. Expected: mot ledger entry, mot outbox, mot inbox/history.
  HTTP 200 webhook cung co the ghi nhan exception, khong du de ket luan da thanh toan.
- Dung cac Order test rieng cho wrong amount/late; Admin xem payment exceptions;
  Customer phai bi tu choi. Khong dung fixture cho du lieu khach hang that.

Ngrok neu chay qua Gateway Compose:

```powershell
ngrok http 8080
```

URL webhook: `https://<domain-ngrok>/payment/internal/v1/sepay/webhooks`.
Khong dung URL Render cu hay endpoint cua Commerce. Backend HMAC hien tai
yeu cau `X-SePay-Timestamp` (Unix seconds), `X-SePay-Signature: sha256=<hex>`,
HMAC-SHA256 cua `<timestamp>.<raw UTF-8 body>`, sai lech gio toi da 5 phut.
Collection mo phong contract nay; chua co bang chung webhook HMAC truc tiep
tu SePay/ngrok. Can doi chieu request thuc te voi contract truoc khi ket luan
thanh toan ngan hang that hoat dong. Ngrok chi can cho callback tu ngoai may.

401: kiem tra credential/signature va dong ho; 502/503 checkout: kiem tra
Payment da chay va creation token hai dau; Payment settled nhung Order chua
PAID: kiem tra dispatcher flag, reverse token, inbox va exception Admin.
Database authentication failed voi volume cu: khoi phuc credential phu hop,
khong `docker compose down -v` de sua loi.
