# StyleMind - Instructor Feedback

## Product Focus

- The project should focus clearly on either women's or men's fashion.
- Preferred direction: women's fashion.
- Smart Wardrobe / personal wardrobe styling should become an important part of the product.
- Clothing products should consider brand information.
- Size and fit are important factors in styling.
- Color coordination should be part of the styling intelligence.
- Travel context and trip duration should be considered when planning outfits.
- Strong visual presentation is encouraged.
- Live 3D visualization would significantly improve the presentation and experience.

## Interpretation Constraint

These points describe product direction.

They must NOT automatically be interpreted as permission to introduce arbitrary technical implementations such as:

- computer vision,
- photorealistic virtual try-on,
- garment physics,
- diffusion-based try-on,
- automatic body scanning,
- automatic clothing segmentation.

Those require separate approval and specification.
