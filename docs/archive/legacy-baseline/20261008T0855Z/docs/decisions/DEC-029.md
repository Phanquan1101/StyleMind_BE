# DEC-029 — Outfit Promises and AI Acceptance Approach

## Approved decision

V1 AI Stylist promises are:

1. Recommend outfits using user context such as occasion, intended use, style and general weather context manually supplied by the user.
2. Prioritize appropriate reuse of existing Wardrobe items and combine them with Catalog products where useful.
3. Ensure that 100% of products presented as purchasable map to real Catalog Product/Variant entities. Hallucinated purchasable products are prohibited.
4. Obey applicable hard constraints. Examples include excluded category, prohibited color, explicitly excluded product/type and a maximum budget when supplied as a hard limit. Hard constraints override aesthetic preference.

V1 size and fit guidance is advisory only. There is no exact-fit guarantee and the user makes the final size selection before adding an item to the cart. General fashion color coordination is allowed, but there is no deep skin-tone analysis or professional Personal Color Analysis promise.

V1 does not require a real-time weather API, automatic multi-day travel outfit planning or automatic packing optimization. User-provided general weather/context may be used as ordinary styling context.

Acceptance uses scenario-based Pass/Fail testing. Mandatory PASS properties are real Catalog mapping for every purchasable item, correct distinction between owned Wardrobe items and Shop items, and compliance with applicable hard constraints. Mandatory FAIL examples are hallucinated or invalid purchasable products, incorrect owned/shop representation and hard-constraint violation.

## Scope implications

The BRD may state these product promises and acceptance invariants. They do not select an AI model/provider or technical runtime, and they do not create a subjective quality threshold.

## Explicit exclusions and deferred items

- Aesthetic accuracy percentage, recommendation relevance percentage, fashion taste score, arbitrary AI accuracy and Personal Color Analysis accuracy remain TBD.
- Exact model/provider, failure/fallback behavior, latency and cost limits remain for later AI/runtime specification.
- Exact outfit structure, detailed budget interpretation and all unresolved implementation mechanisms remain TBD unless explicitly defined by another approved decision.
