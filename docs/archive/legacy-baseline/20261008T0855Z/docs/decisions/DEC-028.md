# DEC-028 — Smart Wardrobe Capability Boundary

Status: APPROVED

Decision Authority: Phan Đoàn Thế Quân — Solo Developer & Product Owner

Date: 2026-09-21

Source Decision Review: DR-010

Resolved OPEN Questions: OPEN-032, OPEN-033, OPEN-034

## Approved decision

Smart Wardrobe V1 includes:

1. Wardrobe CRUD: create/add, view, update and delete a wardrobe item.
2. Personal clothing image upload.
3. Basic item metadata: category, primary color, occasion and/or style.
4. Visual browsing through list/grid or an equivalent view with category-based organization.
5. AI Stylist integration, so wardrobe items become AI context and appropriate owned-item reuse is prioritized with real Catalog products.
6. A clear distinction between `YOU ALREADY OWN` and `RECOMMENDED TO BUY` in AI output. Owned items resolve from Wardrobe data; purchasable recommendations resolve from Catalog data.

Initial category concepts are Tops/Áo, Bottoms/Quần, Dresses/Váy, Shoes/Giày and Accessories/Phụ kiện. These are product concepts, not a final database enum design.

## Scope implications

The primary V1 acceptance rule is that a user can save an item into Wardrobe and the AI Stylist can validly use that stored item together with real Catalog items in an outfit. Wardrobe item identity, metadata and catalog provenance must remain distinguishable, while the technical data model remains for a later specification.

## Explicit exclusions and deferred items

V1 excludes sophisticated computer vision, complex background extraction, garment segmentation from cluttered images, automatic wardrobe extraction from full-body selfies, automatic clothing recognition from body photos, wear-history tracking, outfit wear diary, laundry state, wardrobe analytics and cost-per-wear analytics.

Automatic import, image recognition, clothing segmentation, a dedicated wardrobe service, favorites, saved-outfit history and other optional operations are not approved unless separately specified. Exact image limits, retention, access and data ownership remain TBD where not defined by this decision or existing confirmed requirements.
