# Legacy baseline archive

This directory preserves documentation and generated contracts from earlier StyleMind specification and architecture phases. These files are historical/reference material; do not use them as implementation instructions or as the current product, service, database, API, event, or security baseline.

Use only assertions that do not conflict with the current owner-approved context, and verify them against current sources before relying on them. The original files are retained byte-for-byte; see [MANIFEST.md](MANIFEST.md) for their original and archive paths, classifications, reasons, and verified SHA-256 hashes.

Current implementation guidance is in [CURRENT_PROJECT_CONTEXT.md](../../../governance/CURRENT_PROJECT_CONTEXT.md), [CURRENT_BUSINESS_RULES.md](../../../governance/CURRENT_BUSINESS_RULES.md), and [OPEN_IMPLEMENTATION_DECISIONS.md](../../../governance/OPEN_IMPLEMENTATION_DECISIONS.md). The current six-service logical model is in `database/six-service-model/` outside this archive; Identity physical schema is defined by V1–V3 migrations.

Historical decision IDs, including DEC and OPEN/DR references, are preserved unchanged. Archiving does not close open questions or silently amend the original decisions.
